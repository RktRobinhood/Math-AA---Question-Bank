Trapezoidal approximation

Approximate an integral using equally spaced strips.

1.1Calculator

Four equal strips

    Try it yourself

    Calculator routes and practice limits

    On a Calculator page, choose Menu → 1: Actions → 1: Define. Enter f(x)= followed by the rule, then press Enter. Type the weighted expression manually, using f(number) for each ordinate. There is no Trapezoid key in this walkthrough.

    Use equal strips. With spacing h, multiply the sum of the endpoint heights and twice the interior heights by h/2. The weighted calculation estimates the signed integral; it does not reverse the sign of heights below the axis.

    Try accepts polynomials in x up to degree eight, bounds from −40 to 40, and 1–12 strips. Type * for multiplication. This is a lesson simulator, not firmware.

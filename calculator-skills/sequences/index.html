    Calculator routes and practice limits

    Consecutive sum: Calculator → Menu → 4: Calculus → 3: Sum. Enter the index letter first; Tab goes to the lower bound, upper bound and rule. The TI reference also documents typing sumSeq(rule,n,lower,upper).

    Stepped sum: Menu → 6: Statistics → 3: List Math → 5: Sum of Elements, then add seq inside it from 6: Statistics → 4: List Operations → 5: Sequence. The last argument is the step. seq alone returns the list, stopping at the last index at or below the upper bound.

    The practice calculator accepts n, decimal constants and + − × ÷ ^ (use * when typing multiplication). Use integer indices between −1,000 and 1,000, increasing ranges up to 80 terms, and positive integer steps. This is a lesson simulator, not TI firmware.

    Looking for the first term above a target? Check the actual sequence values at integer indices. If you use a continuous crossing to estimate where to look, test the neighboring integer indices in the original rule. Use a stepped list to check candidates when needed.

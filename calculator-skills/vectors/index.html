Find the dot product and the angle for these rows.

1.1CalculatorDEG

Use the keypad

Key paths

Store: a or b, Ctrl + templates, then Menu → 7 → 1 → 1. Set 1 row and 2 or 3 columns. Tab between dimensions or cells.

Scalar: Menu → 7 → C → 3. Type a,b), then Enter.

Angle: trig, select cos⁻¹, then Ctrl + ÷. Put dotP(a,b) above and norm(a)×norm(b) below. Menu → 7 → 7 → 1 inserts norm(. The down arrow moves below the fraction bar.

Computer keyboard: M opens Menu, T opens trig, : then = inserts assignment, and F opens the fraction inside cos⁻¹.

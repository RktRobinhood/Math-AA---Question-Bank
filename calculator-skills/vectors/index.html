    Use the keypad

    Key paths

    Store: a or b, Ctrl + templates, then Menu → 7 → 1 → 1. Set 1 row and 2 or 3 columns. Tab between dimensions or cells.

    Scalar: Menu → 7 → C → 3. Type a,b), then Enter.

    Angle: trig, select cos⁻¹, then Ctrl + ÷. Put dotP(a,b) above and norm(a)×norm(b) below. Menu → 7 → 7 → 1 inserts norm(. The down arrow moves below the fraction bar.

    Computer keyboard: M opens Menu, T opens trig, : then = inserts assignment, and F opens the fraction inside cos⁻¹.

    Captions only
    Formula, units, and sources

    The dot product is a single number: multiply corresponding components and add. For nonzero vectors, cos θ = (a · b) ÷ (|a| |b|). Apply inverse cosine to get the angle from 0° to 180°, or 0 to π radians. A zero vector still has dot product 0, but no direction, so the angle is undefined.

    Use the angle unit requested by the question. The rehearsal opens a Calculator page in the task’s unit. On the physical TI, set it in Document Settings. Angle mode lesson.

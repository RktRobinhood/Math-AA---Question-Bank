Handset keys shows an exact fraction in Auto and Ctrl + Enter for a one-off decimal.

Open a blank Scratchpad. Try sin(45) in both DEG and RAD using the angle indicator. Then compare Enter and Ctrl + Enter on 11÷7. Check what changes and what does not.

On your own CX II-T, check Float 6, Angle and Calculation Mode in Document Settings. The browser Scratchpad does not reproduce that full menu.

If a plot disagrees with your Calculator page, check the separate Graphing Angle in Graphs settings. A manually selected unit can override the document setting.

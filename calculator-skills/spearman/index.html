AI SL and HL · Rate monotonic association using paired ranks.

    Enter your ranks in named lists rx and ry. Then open Menu → 4 → 1 → 4. Select the two rank lists; read the result labelled r, not r².

    How do I handle a tie?

    Rank the values in each list separately, smallest first. If two values occupy ranks 2 and 3, both get 2.5. The next value has rank 4. Enter the ranks on their original paired rows. Do not sort one column independently.

    Why use ranks?

    Spearman correlation measures monotonic association, not just linear association. It is Pearson r calculated on the paired ranks. Use ascending ranks for both columns and average any ties. A constant rank list gives undefined correlation.

Lists & Spreadsheet

AI SL and HL · Rate monotonic association using paired ranks.

    Enter your ranks in named lists rx and ry. Then open Menu → 4 → 1 → 4. Select the two rank lists; read the result labelled r, not r².

    How do I handle a tie?

    Rank each list separately, smallest first. For any tied group, average the positions it occupies and give each member that average. For example, ranks 2 and 3 both become 2.5; the next rank is 4. Put the ranks back onto the original paired rows.

    Why Pearson r? The squared-rank-difference shortcut assumes ranks 1 to n each occur once in each list. Ties change the spread of the ranks; Pearson r uses the spread of the rank lists you actually entered.

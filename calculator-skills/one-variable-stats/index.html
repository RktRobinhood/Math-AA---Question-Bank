Readings and counts

Each value is a reading. Its frequency tells you how many times it occurs.

    Sample or population?

    Use σx (divide by n) for the standard deviation of the whole collection being described. Use sx (divide by n−1) when the task asks for the sample standard deviation. Both are in the original units. Frequency List 1 uses each row once. Counts of zero exclude those rows. Keep the result columns separate from the named source lists.

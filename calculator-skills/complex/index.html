Find the modulus and principal argument.

1.1CalculatorDEG

Use the keypad

Key paths

Home → 5 → 2 opens Document Settings. Choose the requested Angle units and Rectangular for a + bi, or Polar for modulus–argument display. Confirm, then choose Current.

Enter the imaginary unit from the π palette. On a computer, type @ then i. Type abs(z) for the modulus and angle(z) for the principal argument. Ctrl + Enter requests an approximate value.

You can also append Catalog → P → ►Polar to an input for one polar display, leaving the settings unchanged. To go back to rectangular form, select Rectangular and enter a polar value in parentheses, for example (2∠90) in Degree mode.

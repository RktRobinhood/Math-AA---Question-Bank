CT39 Normal intervals and tails · CX II-T non-CAS teaching reconstruction

Open normal/index.html beside the shared handheld/ folder. The staged lesson is
caption-only, includes no audio or firmware, and works offline. No measured
cue sheet, script timing, media code or keys were changed in this revision.

Watch demonstrates a bounded interval (mu 20, SD 2, endpoints 18 and 23)
then an upper tail beyond 22, with deterministic key lights and seek. Press
the central Play or use the transport. Short screens start in Focus (Escape
or Exit focused view to leave it). Mid-Watch Take over pauses and copies the
exact calculator frame; Return restores the paused Watch time and focus.
Up to 32 distinct cursor drafts are held for this page session. Return to
your Try leaves the fork without deleting it. End-of-Watch Open Try and the
Try tab open the independent exercise, preserving learner draft, conditional
workbench and correct/wrong feedback. Reset Try restores that assignment.

Calculator workflow: Menu > 5 Probability > 5 Distributions > 2 Normal Cdf.
Menu > 6 Statistics > 5 Distributions > 2 also reaches it. Fields are lower,
upper, mean and SD; confirm OK to insert the command and Enter to evaluate.
In the reconstruction unbounded endpoints start at ±∞. In its wizard, use
the physical Tab/number keys, a keyboard or touch; enter “infinity” on the
simulator for an unbounded field. The TI reference documents −9E999 for a
lower-tail lower bound. The simulation additionally accepts signed 9E999
sentinels for bound fields only. Focus the shell (or press M from the Try
panel/body). Enter opens no answer unless arguments are valid and submitted.
The normal curve is continuous; including an endpoint does not affect area.

Standalone ?mode=try opens the original upper-tail exercise with a neutral
calculator. Legacy ?mode=try&example=demo also remains valid; its wizard
sets model parameters but leaves the threshold blank for the student.
Bank integration accepts one complete tuple (do not mix with example=demo):
  ?mode=try&event=upper&lower=35&mean=32&sd=3
  ?mode=try&event=lower&upper=33&mean=32&sd=3
  ?mode=try&event=range&lower=13&upper=19&mean=17&sd=3
Omit the unbounded endpoint for a tail. All supplied numbers must be finite;
positive SD, ordered finite range, |means| and SD <= 10^9, |bounds| <= 10^10,
one value per recognized input. Invalid links visibly fall back to original
Try. Links transmit input only, never the probability. The exercise checks
the linked event (four decimal places); the optional workbench supports
editable variants, with the fixed assignment hidden when loading a different
case and restored on Reset. View the calculator result to see its normal
curve. Implausibly tiny positive probabilities below representable magnitude
are described as below display range rather than exactly zero.

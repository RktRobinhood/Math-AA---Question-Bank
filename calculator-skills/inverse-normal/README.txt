CT40 · Inverse Normal
Captioned rehearsal using the TI-Nspire CX II-T non-CAS teaching shell,
not firmware. The question-bank Watch controls belong to the lesson.

Watch uses the 75th percentile and top 10% of a common distribution
(mean 50, SD 8). Calculator → Menu → 5 Probability → 5 Distributions
→ 3 Inverse Normal. Wizard: left Area, mean, standard deviation.
Confirm with Enter, then Enter again to evaluate the inserted command.
The learner converts a right-tail probability; no Tail selector is
shown. The chart is a lesson illustration, not on the device itself.

Watch starts in Screen view and shares the saved Screen/Full preference
with other supported lessons. The bottom controls play, seek, set speed,
show the caption script and enter fullscreen. The key readout is separate.
Try always uses the full calculator. Edit the distribution in the LCD
wizard; the separate written checker covers only the practice prompt.
Going back to Watch does not replace your Try work. Reset restores it.

Typed handoff: ?mode=try&tail=right&p=.15&mean=57&sd=6
Right-tail links show the original right area and prefill μ, σ in the
wizard; Area remains empty. Left links can prefill the given left area.
All three givens required exactly once; tail defaults to left. Use
?mode=try&example=demo alone for the independent default. Partial,
duplicate, invalid, or unusable input falls back visibly with no result.

Model bounds: Area from 10^-15 through 1−10^-15, |μ| at most 10^9,
positive SD no greater than 10^9; an unrepresentably small spread is
rejected. LCD simulation displays up to 13 significant digits; the
checker accepts the required 2 d.p. rounded from the visible result
or from the internally retained cutoff. No audio is shipped here.

The optional embedded ct40-narration-manifest contract is unchanged:
watch-media.js adopts already-verified local audio only with measured
cue, key and tail-context times and a matching decoded duration.
narration.js remains the captioned rehearsal source.

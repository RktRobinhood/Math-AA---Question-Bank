    Calculator and lesson scope

    From a Data & Statistics page, bind a numeric list already entered in the same problem to the horizontal axis. You can also start from a named list. Use Menu → 1: Plot Type → 2: Box Plot. The default is modified. Plot Properties contains Extend Box Plot Whiskers and, after extending, Show Box Plot Outliers.

    For the lesson, sort the data and use the median of each half for Q₁ and Q₃; omit the middle observation when the count is odd. The mathematical 1.5 × IQR rule flags only values strictly outside the fences. Matching real handheld behavior for observations exactly on a fence has not been tested. Use 4–32 finite observations, with at most four decimal places.

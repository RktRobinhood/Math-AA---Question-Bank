    Expected counts, not percentages

    For a fixed distribution, multiply the total observed count by each claimed probability to get the expected counts. The lists must have the same total and order. With no parameters fitted from the data, df is the number of categories minus 1. In the current IB exam examples each expected count exceeds 5.

    Note down: χ² goodness-of-fit tests one variable against a claimed distribution. χ² independence tests an association between two categorical variables.

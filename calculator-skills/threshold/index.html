    What this practice viewer supports

    The practice viewer supports positive exponential models in the form A*B^x and positive horizontal targets reached strictly inside the time interval. Bases must be between 0.1 and 4, excluding 1; the end of the interval must be a whole day between 2 and 30. A growing model uses “at least”; a decreasing model uses “at most”. Other kinds of thresholds exist; this is a rehearsal of the menu, not calculator firmware.

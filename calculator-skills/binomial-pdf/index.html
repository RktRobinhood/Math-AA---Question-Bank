    PDF or CDF?

    Exactly 3: include 3 only. Use binomPdf(n,p,3).

    At most 3: include 0, 1, 2 and 3. Use binomCdf(n,p,0,3).

    The TI can return a full probability list if X Value is blank. This lesson always asks for one count.

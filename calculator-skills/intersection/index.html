Keyboard: M, 6, 4; arrow keys move the cursor, or type a bound. Enter confirms. Use the onscreen Tab key to open f₂.

Set exercise

Give exact values when you know them. You can also enter the displayed values to check your work.

Hint

Put one bound on each side of the same crossing. Both functions have the same output at its x-coordinate.

Exploring a different pair

The set exercise is paused. Reset the calculator to return to it.

For two linear equations, use LinSolve.

Narration transcript

Plot both functions on the same page. Look for the crossing that matches the requested point. Choose Intersection. Select the relevant graphs if prompted. Bracket one crossing at a time with the lower and upper bounds. Read the coordinates. At the intersection, both expressions give the same y-value.

Calculator Skills / CT09

Keyboard: M is Menu. Use arrows, digits and Enter. On a desktop, use Menu rather than the browser’s reserved Ctrl + T shortcut.

Set exercise

Find the function value

Use Graph Trace or a table to find f(−2) for f(x) = 3x² − 2x + 1.

Hint

Your calculator workspace

Try another input or switch between Trace and Table. Reset to return to the set exercise.

Narration transcript

On a Graphs page, plot f of x equals two x squared minus three. Open Menu then five: Trace then one: Graph Trace. Step along the curve with the arrows. To jump to a given input, type its x-value and press Enter. Read the second coordinate. Press Esc to leave Trace. Open a split-screen table with Control and T, or use Menu then seven then one. Auto gives a regular list. Focus the table and use Menu then two: Table then five: Edit Table Settings. Change Independent to Ask. Type the x values you want in the x column. Read each result from the same row in f one of x. Trace locates a point on the graph. A table keeps the results for multiple inputs together.

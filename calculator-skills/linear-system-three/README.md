# Solve a 3×3 linear system

This is the standalone companion to [two-variable LinSolve](../linear-system/). It reuses the single-device Watch template. The original Watch example is uniquely solved at (3, 1, 2); the independent Try has three initially blank LCD input rows and a different system. Results never appear before Enter. Row editing and the exact solver accept linear sums in x, y and z with integers or decimals up to three places. Calculator output order follows the comma-separated Variables field. Singular Try cases report a mathematical classification, not the handset’s exact parameter notation.

- [TI's non-CAS Calculator menu walkthrough, p.16](https://education.ti.com/-/media/ti/files/resources/student-parent/ti-nspire-best-practices.pdf#page=16) shows Calculator → Menu → 3: Algebra → 2: Solve System of Linear Equations and the result list.
- [TI's three-equation worksheet, pp.1–2](https://education.ti.com/-/media/A2807A54A985434CBADB26DFEFFA960B#page=1) independently verifies choosing three, tabbing to the comma-separated variables, Tab between equation rows and Enter to evaluate. Its older Algebra submenu arrangement differs from the non-CAS walk-through. No original worksheet problems or artwork are reused.
- [IB Mathematics AA, AHL 1.16, printed p.35](https://www.ibo.org/globalassets/new-structure/university-admission/pdfs/dp-mathematics-analysis-and-approaches-guide-en.pdf#page=41) and [IB Mathematics AI, SL 1.8, printed p.30](https://www.ibo.org/globalassets/new-structure/university-admission/pdfs/dp-mathematics-applications-and-interpretation-guide-en.pdf#page=36) establish AA HL and AI SL/HL scope. AI examinations use a unique solution; this demo does too. The companion is not listed in AA SL.

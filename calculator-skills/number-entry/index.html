What EE means

EE means “times ten to the power of”. For example, 3E−2 is 3 × 10⁻². Read the calculator value first. Keep an exact answer if you have it. Otherwise round only the written final answer, as the question asks. On paper, write scientific notation as a × 10ⁿ.

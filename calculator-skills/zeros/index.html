    Zero or y-intercept?

    A zero is an x-coordinate where the function output is zero. For the y-intercept, use Menu → 5: Trace → 1: Graph Trace. Type 0 for x and press Enter. Read (0, 6): 6 is the y-intercept. The demo uses a window where both intercept types are visible.

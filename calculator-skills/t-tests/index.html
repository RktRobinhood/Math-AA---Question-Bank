    One sample or two?

    A one-sample t-test uses the sample standard deviation, not a known population standard deviation. Paired observations give one sample of differences. Use the two-sample test for independent groups. For IB exam questions using equal population variances, select Pooled: Yes.

    Note down: Choose the direction before seeing p. A large p-value does not establish equal means.

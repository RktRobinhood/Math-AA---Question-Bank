    Method and sources

    Write the system as A·X = b, then put A⁻¹ on the left of b. There is no inverse when A is singular. For this extra diagnostic, rref reduces the three-column array [A | b]; a row 0, 0 | 1 is a contradiction. An all-zero row imposes no condition. This simulator covers only the keys and matrix operations used in the lesson.

Graphical inequalities

Find where one graph lies above or below another. Keep undefined points out.

Where is f₁(x) ≤ f₂(x)?

f₁(x) = (x² − 4)/(x − 1)
f₂(x) = 0
−4 ≤ x ≤ 4

    Write the solution set

    Hint

    Split at intersections and at any zero of the original denominator. Test one point in each interval. Strict inequalities leave out equal endpoints; an undefined point is always excluded.

    Use U for union, {a} for a single point, or “empty”. Round endpoints to at least 6 significant figures.

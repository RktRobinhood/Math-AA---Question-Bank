    Raw list or frequency table?

    Raw data: each reading gets its own row. Frequency table: each value appears once, with its count beside it. A zero count is not an empty cell. Named columns become list variables in the current problem. The formula row is not the first data row. Use Tab to switch between the naming and data zones. Select an LCD cell to edit it; Enter stores your entry and moves down in the data rows.

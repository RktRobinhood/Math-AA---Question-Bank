    Keys and practice limits

    Use the arrows to select cells. In a numbered row, Enter stores your value and moves down. Use the handheld Tab key to switch between naming and data zones. Selecting an LCD cell with a tap is a practice shortcut. This lesson supports two columns, six rows, and short distinct names.

    Raw list or frequency table?

    Raw data: each reading gets its own row. Frequency table: each value appears once, with its count beside it. A zero count is not an empty cell. Named columns become list variables in the current problem. The formula row is not the first data row.

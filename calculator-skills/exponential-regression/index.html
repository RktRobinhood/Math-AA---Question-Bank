    What ExpReg actually fits

    TI fits a line to x and ln(y), so each y must be positive. The resulting model is y = a·bx. The number a is the model estimate at x = 0, not necessarily a measurement. The number b multiplies the estimate each time x increases by one; the percentage change is 100(b−1)%.

    Interpolation uses a new input inside the observed span. Extrapolation goes beyond it and assumes the trend continues. The reported r and r² describe the log-transformed line. TI reference for ExpReg.

    Calculator routes and practice limits

    In Graphs, x is time. Go to Menu → 6: Analyze Graph → 1: Zero to bracket a crossing. Confirm the lower and upper bounds, then mark the zero with Enter. Test the velocity on each side: a zero that only touches the axis is not a reversal.

    On the non-CAS/Exact Arithmetic CX II-T, Menu → 6: Analyze Graph → 6: Integral takes the lower and upper bounds. The result keeps its sign. For distance, repeat on each interval between reversals and add the magnitudes of these signed results. A true zero of velocity at a domain endpoint does not split the interval.

    This lesson simulator supports polynomials of degree 0 to 4 with coefficients from −1000 to 1000, decimal time bounds from 0 to 15, and the named Graphs tools. It is not TI firmware. Its Zero exercise isolates sign crossings; real calculator root-finding behavior near touch points can vary.

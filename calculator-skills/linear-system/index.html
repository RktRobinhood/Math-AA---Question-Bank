    Read and check the pair

    Use Calculator Menu → 3: Algebra → 2: Solve System of Linear Equations on the non-CAS menu. In {x,y} order, the first entry is x and the second is y. Check that the pair satisfies both equations. A parallel pair with different constants has no shared solution; identical lines have infinitely many.

    The reconstructed LCD uses a short message for a dependent system; the TI may instead give a free parameter. Some Press-to-Test settings disable the solver.

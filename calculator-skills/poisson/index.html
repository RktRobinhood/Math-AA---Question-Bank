    Calculator and lesson scope

    This lesson types poissPdf and poissCdf on the Calculator page. A typed command evaluates with one Enter. If your model has a distribution dialog, the first Enter inserts the command and a second Enter evaluates it. Find commands by name or type them; menu shortcuts can differ.

    Use a positive mean for the requested observation interval. This simulator accepts λ from 0.0001 to 120 and integer counts 0–150; more extreme results may be below the simulator’s numerical range. Built-in probability names are supported, not arbitrary calculator expressions.

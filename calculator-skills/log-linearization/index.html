AI HL · Semi-log transformation for an exponential model.

    Linear regression: M, 4, 1, 3. Use arrows and Tab to select lists; Enter runs the calculation.

    Build the transformed column

    Select the name cell of column C and type lny. Press Enter. In the formula cell below, enter ln(yval) and press Enter. On the handheld, Ctrl + eˣ inserts ln(; on the computer, type the formula. The list assignment is already there. Then choose xval for X and lny for Y.

    Edit paired data

    From the line in ln(y), find the original exponential coefficients. Predict at the first input and classify both inputs. Keep the fitted digits for predictions. If rounding a submitted answer, use at least three significant figures.

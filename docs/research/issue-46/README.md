# Question Builder: interactive feasibility prototypes

Design evidence for [issue #46](https://github.com/RktRobinhood/Math-AA---Question-Bank/issues/46). This branch is not deployed and does not change the application, practice, test builder, or archived papers.

Download `index.html` and open it locally. The single file works offline.

- **A · Image mask.** Toggle part (b) on the simulated scan. Notice the obsolete total and the remaining reference to part (b).
- **B · Editable parts.** Toggle the original wording to expose the dependency; switch back to the author-approved alternative. Compare Student paper and Teacher key. Both reletter the kept parts and display four marks.
- **C · Question variants.** Change the coefficient or reroll; check the corresponding key and fix a variant in this demo session. The controls use a small, prevalidated set of values.

**Sample:** original fountain model. All screenshots use the same original problem to make the trade-off clear. No IB questions, keys, logos or source screenshots are included. The demo is not a distribution, privacy, or security model; its teacher key is deliberately available for testing.

**Verified:** all three core interactions in Chromium; 12 mode/viewport/theme combinations at 390, 768 and 1440px; all four parameter/key combinations; and a browser-printed 4-mark PDF containing the two selected parts with no omitted prompt. No production exporter, editable DOCX, physical device, or archival conversion tested.

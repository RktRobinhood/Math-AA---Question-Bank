# 0003 · Reuse Watch for contextual help in generated Practice

Status: Accepted

When an eligible generated exercise has a reviewed Calculator Skills match, offer a small help button inside the open Scratchpad. Open that lesson's existing Watch player in a centered dialog, adapting it to the phone viewport, rather than sending the learner away or building separate help content. Only one surface is interactive at a time. Close the dialog to return to the unchanged question and Scratchpad. Keep Watch's separate example: pass no given, draft, answer, learner progress or seed, and omit the shortcut if an exercise duplicates the Watch example. Require a reviewed form-to-lesson match rather than guessing from an entire topic; no shortcut on real exam questions or in the lesson itself.

Evidence: [Practice access and route matching](../../assets/js/practice-calculator.js), [Watch player contract](../calculator-skills/PLAYER-CONTRACT.md), and [ADR-0002](0002-isolate-practice-scratchpad.md).

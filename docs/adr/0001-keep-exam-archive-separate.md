# 0001 · Keep the exam archive separate from calculator rehearsal

Status: Accepted

Keep official past-paper questions and markschemes in the archive with permanent question IDs; a question shared by SL and HL is stored once, with each appearance retaining its own paper and printed number. The alternative, copying appearances or adding worked calculator tools to exam questions, could improve access in one place but would blur provenance and change what a student sees under exam conditions. A real question remains archive material when Practice serves it as fallback or review: no inline calculator or lesson, even for a calculator paper. Standalone Calculator Skills uses original examples. The shared site header can link out to Practice and Calculator Skills; it is navigation only and does not add those tools to the archived question.

Evidence: [question identity and appearances](../../README.md#question-ids), [shared appearances](../../data/shared.json), [paper policy](../../data/courses.json), and [Calculator Skills scope](../calculator-skills/COVERAGE-REVIEW.md#official-exam-access-vs-narrower-launch-policy). For original exercises see [ADR-0002](0002-isolate-practice-scratchpad.md).
